# Matty Costa Paz — sitio web

Portfolio de Matty Costa Paz, diseñadora de interiores. Astro, español e inglés (`/en/`).

```bash
npm install
npm run dev     # http://localhost:4340/
npm run build
```

Para publicar: `bash deploy.sh` (compila y sube `dist/` a la rama `gh-pages`).

- Datos y textos: `src/data/site.js` (lo que falta va como `[COMPLETAR]`).
- Fotos de proyectos: `src/assets/projects/<proyecto>/` (Astro las convierte a WebP).
- Logos de prensa: `src/assets/press/`.
